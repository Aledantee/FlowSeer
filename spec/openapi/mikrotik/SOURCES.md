# MikroTik RouterOS REST API spec sources

## routeros-7.24-openapi.json

- OpenAPI 3.0.3 schema for the RouterOS v7 REST API (v7.24, 3652 paths).
- Source: https://tikoci.github.io/restraml/7.24/openapi.json (project: https://github.com/tikoci/restraml)
- Downloaded: 2026-08-20
- NOT official MikroTik. MikroTik publishes no machine-readable spec for the
  RouterOS REST API (open feature request:
  https://forum.mikrotik.com/t/feature-request-openapi-for-rest-api/149360).
  This schema is community-generated by the restraml project, which runs
  `/console/inspect` against a live RouterOS instance, so it mirrors the
  console command tree: endpoints and argument names are accurate, but many
  argument types are `any`, response attributes are imprecise, and there are
  no descriptions.
- Official REST API docs (human-readable only):
  https://help.mikrotik.com/docs/spaces/ROS/pages/47579162/REST+API

## Protocol notes

- RouterOS v7 REST API: HTTPS JSON wrapper over the console API (www-ssl
  service). Read + write. Preferred over SNMP for config-shaped data.
- RouterOS also has the proprietary binary API (ports 8728/8729); no schema.
- No NETCONF/RESTCONF/gNMI support and no YANG models exist for RouterOS.
- SwOS / SwOS Lite switches (CSS/CRS in SwOS mode): SNMP read-only, no REST
  API; the MIKROTIK-MIB in ../../mib/mikrotik/ covers them.
