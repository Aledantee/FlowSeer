## Why not owned code

FlowSeer would have to implement the ClickHouse native binary protocol, column encodings, block compression, connection pooling, and failover across endpoints. That is a vendor wire format that changes with each server release, and the research for the history store found no smaller maintained client that offers pooling and per-query settings ([research 01, section 1](../../../../../../research/clickhouse-history-store/01-clients-durability-dedup.md)).
