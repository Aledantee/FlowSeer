Contract:

- Pending host injections and attached stream frames are released through one time-ordered loop before each step chooses the next arrival. The release picks the earliest of the two, and no released frame carries a time earlier than one already released in the run, so the simulation clock never moves backward across steps.
- A host injection transmits immediately at `Inject` when no queued arrival precedes its requested time and no earlier host injection is already pending before the first step. When a queued arrival precedes the requested time, or a host injection is already pending, the injection is deferred and released later in time order rather than transmitted eagerly.
- Deferred host injections are released in ascending time order regardless of the order they were injected in. A later-injected but earlier-timed host frame is released before an earlier-injected but later-timed one.
- The link state and the host end's busy clock are evaluated when the frame transmits, at `Inject` for an immediate transmission and at release for a deferred one. A fault set after a deferred injection but before its release changes that injection's outcome; an immediate transmission is already committed and a later fault does not change it. A host whose link is not `Up` at transmission time records a drop or an unresolved entry at the injection time and transmits nothing.
- The eager and the deferred paths produce the same deliveries. A run that injects every frame eagerly and a run that attaches a stream for the same frames deliver the matching flows at the same times.
- Attached stream frames due no later than the earliest queued arrival are pulled before the step; when the queue is empty, the earliest frame is pulled to keep the run moving. Eager host injections win ties with stream frames, and streams at the same time follow attachment order.
- `RunScenario` refuses a scenario that carries actions while any stream is attached, returning an error that names the attached stream, because the release order does not account for action times. A scenario with no actions, or a run with no attached stream, is unaffected.
- The retention decision for a released frame matches the decision the same frame receives on the eager path, so a deferred injection is retained or folded exactly as an immediate one.
