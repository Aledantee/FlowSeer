# Sensitive units

Load this when a unit's changed path matches `sensitive_paths`.

- The unit routes `execute-sensitive`, whose `fit` order and Opus 4.8
  `last_resort` are the user's. A review of it may run on Claude like any
  other review.
- Its brief, and the coordinator's own text about it, name paths and the
  change, never a catalogue of what the tooling attacks: the classifier
  fires on enumeration alone.
