# Sensitive units

Load this when a unit's changed path matches `sensitive_paths`, the globs
the effective registry holds under that top-level key.

- The unit routes `execute-sensitive`, whose `fit` and `last_resort` are
  the user's. A review of it may run on Claude like any
  other review.
- Its brief, and the coordinator's own text about it, name paths and the
  change, never a catalogue of what the tooling attacks: the classifier
  fires on enumeration alone.
