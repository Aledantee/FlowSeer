# Overruling a delegate

Load this when a brief decides against a delegate's proposal, or would
repeat an override of an earlier worker.

- A decision against a delegate's proposal states the failure it avoids in
  terms the delegate can check in the tree. A bare preference can only be
  complied with, and a delegate that can only comply also complies with the
  coordinator's mistakes.
- A ledger `note` records what the next unit needs to know about what
  landed, not a rule. When an override of a worker will recur, edit the
  convention doc that governs the file type, in its own reviewed change,
  before the next dispatch, or leave the override out of the brief. A brief
  that names a convention doc as authoritative and contradicts it in a note
  leaves the worker between two sources with no rule for which wins.
